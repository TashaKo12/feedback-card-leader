# Карточка обратной связи по пробному занятию

Шаблон для онлайн-школы «Лидер». Преподаватель заполняет карточку сразу после пробного занятия и отдаёт родителю в виде PDF или картинки. Один файл, без установки, без интернета, без сборки.

**Файл:** `index.html`

---

## Что это такое

Обычная HTML-страница, которая открывается двойным кликом в любом браузере. Внутри — лист A4 в фирменном стиле школы. Все тексты на листе редактируются прямо на странице: кликнул и печатаешь, как в документе. Кнопка «Печать / PDF» сохраняет результат в готовый файл.

Шаблон решает одну конкретную задачу: превратить рабочие заметки менеджера («мотивация средняя, заставили, техника не тянет») в документ, который не стыдно отправить родителю.

---

## Как работать

### 1. Открыть

Двойной клик по файлу. Откроется в Chrome, Safari, Edge, Firefox — в любом. Интернет не нужен, шрифт и вся графика лежат внутри файла.

### 2. Заполнить

Кликнуть по любому тексту на листе и печатать поверх. Редактируются все поля: имя, дата, направление, списки, абзацы, совет в конце.

**Оценки.** Четыре шкалы: интерес к теме, вовлечённость, самостоятельность, темп работы. Ромбики кликабельны — нажатие на третий ставит оценку 3 из 5. Названия шкал тоже можно переписать.

**Списки.** В блоке «Что делали на занятии» Enter создаёт новый пункт, Backspace на пустом пункте его убирает.

**Блок «Что подготовить к занятиям».** Оранжевый блок про технику. Если проблем не было — кнопка «убрать блок ✕» в его правом верхнем углу удаляет его с листа. Вернуть можно кнопкой «Вернуть блок „Техника"» на верхней панели (страница перезагрузится, несохранённый текст пропадёт).

**Примеры.** Выпадающий список «Загрузить пример…» подставляет одну из семи готовых карточек (GDevelop и Python, разные преподаватели и сценарии). Удобно, чтобы посмотреть тон и объём текста перед тем, как писать своё.

**Очистить** — стирает все поля и обнуляет оценки. Осторожно: отмены нет, только `Ctrl+Z` внутри поля.

### 3. Сохранить в PDF

Кнопка «Печать / PDF» или `Ctrl+P`. В диалоге печати:

- **Принтер:** «Сохранить как PDF»
- **Фоновая графика:** включить обязательно — иначе браузер не напечатает ни сиреневый фон, ни цветные блоки, и лист выйдет белым
- **Поля:** «Нет» (не обязательно, но так красивее — фон дойдёт до самого края)

Панель управления и подсказки в PDF не попадают, печатается только лист.

### 4. Отправить картинкой

Если нужен не PDF, а картинка для мессенджера: сохранить в PDF, затем открыть его и экспортировать страницу в PNG. Либо скриншот листа целиком.

## Технологии

Стек намеренно минимальный: ни сборки, ни зависимостей, ни сервера. Файл должен открываться через пять лет на чужом ноутбуке без интернета.

### HTML

Разметка статическая, вся редактируемость держится на атрибуте `contenteditable`. Браузер сам даёт курсор, выделение, отмену по `Ctrl+Z` и вставку текста — писать редактор не нужно. У каждого редактируемого поля есть `data-field` (по нему скрипт подставляет примеры) и `data-ph` — подсказка, которая видна, пока поле пустое.

### CSS

**Фирменные цвета** вынесены в переменные (`--blue`, `--cyclamen`, `--tangerine`, `--tiffany`, `--magnolia`) и взяты из руководства по фирменному стилю. Поменять цвет во всём документе — одна правка в блоке `:root`.

**Раскладка** — флексбоксы. Лист (`.sheet`) — колоночный контейнер фиксированной высоты A4, содержимое (`.inner`) занимает всё свободное место.

**Подвал** выведен из потока: `position:absolute; bottom:0` по всей ширине листа. Он не зависит от количества текста выше и всегда стоит у нижней кромки. Место под него содержимое резервирует по его фактической высоте — скрипт измеряет её и ставит нижний отступ.

**Слои** через `z-index`: декоративная дуга внизу (0), содержимое над ней (1), подвал сверху (2). Поэтому дуга не перечёркивает текст.

**Печать** описана в `@media print`. Блок делает четыре вещи: прячет панель управления, принудительно включает печать заливок через `print-color-adjust: exact`, задаёт формат страницы через `@page { size: A4; margin: 0 }` и — главное — растягивает лист на всю высоту печатной страницы (`height: 100%`), а не на жёсткие 297 мм. Жёсткая высота ломалась, когда браузер вписывал страницу в область печати принтера: лист заканчивался раньше физического листа и внизу оставалась полоса.

**Адаптив.** До 900 пикселей ширины лист превращается в обычную ленту без фиксированной высоты — чтобы карточку можно было прочитать с телефона.

### JavaScript

Ванильный, без библиотек, около сотни строк.

**Автоподгонка под одну страницу.** Все размеры шрифтов и вертикальные отступы записаны через `calc(14px * var(--k))`, где `--k` — коэффициент масштаба. После каждого изменения текста скрипт сравнивает высоту содержимого с высотой листа и подбирает `--k`: уменьшает шагами по 2% до минимума в 0,70, если текст не влезает, и возвращает обратно к 1,0, если место освободилось. Лист всегда остаётся ровно одной страницей A4. Если текста слишком много даже при минимальном размере, над листом появляется оранжевое предупреждение.

**Шкалы оценок.** Ромбики генерируются скриптом (пять на шкалу), значение хранится в `data-v` на контейнере, клик по ромбику переписывает значение и перерисовывает ряд.

**Примеры.** Массив объектов с готовыми текстами, подстановка идёт по атрибутам `data-field`.

### Шрифт

Geologica — фирменный шрифт школы, вариативный. Вшит прямо в HTML в виде base64 в правиле `@font-face`, поэтому файл ни от чего не зависит.

Исходный файл весил 343 КБ. Перед вставкой он обработан библиотекой `fontTools`:

1. **Инстанцирование** — из четырёх осей (`wght`, `CRSV`, `SHRP`, `slnt`) оставлена только толщина, остальные зафиксированы в значениях по умолчанию.
2. **Сабсеттинг** — оставлены кириллица, латиница, цифры и типографские знаки (кавычки-ёлочки, тире, №), выброшено всё остальное.
3. **Упаковка в WOFF** — сжатие внутри формата.

На выходе 29 КБ вместо 343 КБ при полном сохранении вариативной толщины от 100 до 900.

### Графика

Вся векторная, инлайном в разметке: ромбики шкал, маркеры заголовков, декоративная дуга со звёздами в углу. Ни одной растровой картинки — отсюда и малый вес файла, и чёткость на печати при любом разрешении.

## Как править шаблон

Файл открывается в любом текстовом редакторе. Ориентиры:

| Что менять | Где искать |
|---|---|
| Цвета | блок `:root` в начале `<style>` |
| Поля листа | свойство `padding` у `.sheet` |
| Названия и количество шкал | блок `<div class="scales">` в разметке |
| Заголовки разделов | теги `<h2>` внутри `.block` и `.panel` |
| Тексты примеров | массив `EX` в скрипте |
| Предел уменьшения шрифта | константа `MIN_K` в скрипте |
| Контакты в подвале | блок `<div class="foot">` |

Добавить новый раздел: скопировать любой готовый `<div class="block">` вместе с заголовком и вставить в нужное место — масштабирование и резерв места подхватятся сами.

## Как писать текст для родителя

Техническая часть решена, содержательная — нет. Три правила, по которым переписаны примеры в шаблоне.

**Диагноз меняем на наблюдение.** Не «не факт, что будет готов сидеть и читать наши шаги», а «работать долго по письменной инструкции пока сложно — на первых занятиях понадобится больше внимания преподавателя». Факт тот же, ярлыка нет.

**Наши накладки — наша ответственность.** Про сорок минут установки программы родителю сказать нужно, иначе непонятно, почему успели мало. Но сразу вместе с тем, что мы делаем со своей стороны: пришлём инструкцию заранее, поможем на созвоне.

**Про родителя — только если это действие.** «Мама давит» писать нельзя. «Когда он остался за компьютером один, стал свободнее — рекомендуем оставлять его на занятиях самостоятельно» можно и нужно: это наблюдение с понятным следующим шагом.

Чего в карточке быть не должно: оценок вроде «30 из 10», слов «безнадёжен», «заставили», сравнений с другими детьми и внутренней кухни про наборы групп.

## Если что-то пошло не так

**Лист печатается белым.** В диалоге печати не включена «Фоновая графика». Chrome: «Ещё настройки» → «Фоновая графика». Safari: «Print backgrounds».

**Под подвалом полоса фона.** Поставить в диалоге печати поля «Нет» и масштаб 100% вместо «По умолчанию».

**Шрифт выглядит не фирменным.** Файл был пересохранён с потерей содержимого — взять исходный файл заново.

**Текст мельче обычного.** Сработала автоподгонка: содержимое не влезало в страницу. Сократите описание, и размер вернётся сам.

**Пропал текст после «Очистить» или перезагрузки.** Шаблон ничего не хранит между открытиями. Сохраняйте PDF сразу после заполнения.
